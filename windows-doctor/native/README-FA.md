# SAHROUD WINDOWS DOCTOR 1.0.0

ابزار سبک تشخیص و نگهداری ویندوز مبتنی بر Windows PowerShell 5.1 و Windows Forms.

## اجرا
1. ZIP را Extract کنید.
2. روی RUN-SAHROUD-DOCTOR.bat دوبار کلیک کنید.
3. برای تعمیرات مدیریتی، پنجره رسمی UAC نمایش داده می‌شود.

## امکانات
- مشخصات سیستم، CPU و فضای دیسک
- RAM و برنامه‌های شروع ویندوز
- DISM و SFC با تأیید و UAC
- CHKDSK /scan
- پاک‌سازی TEMP کاربر جاری؛ فایل‌های قفل‌شده رد می‌شوند
- وضعیت و به‌روزرسانی Defender (در صورت پشتیبانی)
- پاک‌سازی DNS و بازنشانی Winsock با هشدار
- ذخیره گزارش روی Desktop

## محدودیت‌ها و ایمنی
- ابزار سرویس‌ها را خودکار غیرفعال یا رجیستری را تغییر نمی‌دهد.
- CHKDSK با /scan اجرا می‌شود و تعمیر آفلاین اجباری ندارد.
- بازنشانی Winsock ممکن است نیازمند راه‌اندازی مجدد باشد.
- پاک‌سازی TEMP ممکن است فایل‌های موقت برنامه‌ها را حذف کند؛ برنامه‌های باز را ببندید.
- این بسته اسکریپتی است، نه EXE امضاشده.
- برای Windows 10/11 و Windows PowerShell 5.1 طراحی شده است.
