دسترسی سریع

بررسی سیستم

این صفحه اطلاعاتی را که مرورگر اجازه دسترسی می‌دهد بررسی می‌کند. وب‌سایت به پردازش‌ها، سرویس‌ها، درایورها یا مقدار واقعی RAM ویندوز دسترسی مستقیم ندارد.

عیب‌یابی کندی ویندوز

موارد زیر را روی رایانه بررسی کنید. نتیجه هر مرحله را انتخاب کنید تا راهکار مناسب نمایش داده شود.

پاسخ‌ها را انتخاب و تحلیل را اجرا کنید.

حافظه و ذخیره‌سازی

برای دریافت اطلاعات قابل دسترس، بررسی اولیه را اجرا کنید.

پاک‌سازی امن ویندوز

این نسخه فقط راهنمای دستی ارائه می‌دهد و چیزی را حذف نمی‌کند.

  1. Settings → System → Storage را باز کنید.
  2. Temporary files را بررسی کنید.
  3. پیش از حذف، Downloads و Recycle Bin را جداگانه بازبینی کنید.
  4. گزینه‌های مربوط به فایل‌های شخصی یا نصب قبلی ویندوز را بدون اطمینان انتخاب نکنید.

امنیت و شبکه

اتصال اینترنت مرورگردر انتظار
وضعیت آنتی‌ویروس ویندوزاز وب قابل بررسی نیست
به‌روزرسانی‌های امنیتیاز وب قابل بررسی نیست

مراحل بررسی امنیت

  1. Windows Security را از Start باز کنید.
  2. Virus & threat protection را انتخاب کنید.
  3. Protection updates را بررسی کنید.
  4. Quick scan را اجرا کنید؛ برای بررسی عمیق‌تر Full scan را در زمان مناسب اجرا کنید.
برای باز کردن تنظیمات ویندوز، کلیدهای Win + I را بزنید و بخش Privacy & security را انتخاب کنید.
