# ماموریت تونل – امیرعلی قهرمان (Android)

این پروژه یک پوسته Android WebView است که فایل HTML بازی را هنگام ساخت APK از
`games/amirali-tunnel/index.html` درون `assets` قرار می‌دهد.

- اجرای بازی کاملاً آفلاین است.
- اتصال به اینترنت برای اجرای بازی لازم نیست.
- اسکریپت‌های آماری بیرونی هنگام بسته‌بندی از نسخه APK حذف می‌شوند.
- جهت اجرای بازی افقی و نمایش تمام‌صفحه تنظیم شده است.
- شناسه برنامه: `com.sahroud.amiralitunnel`

ساخت خودکار از طریق GitHub Actions انجام می‌شود و خروجی Debug APK به‌صورت Artifact منتشر می‌شود.
